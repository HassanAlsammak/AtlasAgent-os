AtlasAgent OS is a developer prototype. Its default workflow runs offline. Optional AI calls transmit the goal to your configured provider and may incur charges. No real desktop automation, user accounts, persistent chat history or production isolation is included.

Keep this server bound to 127.0.0.1. Never publish the demo on the public internet without authentication, CSRF protection, persistent rate limiting and a full security review.
